# WazDevZm.github.io — Personal Portfolio

This is the source code for **Wazingwa Mugala's** personal portfolio website, live at [wazdevzm.github.io](https://wazdevzm.github.io).

## About

A minimal, fast, and fully responsive personal portfolio built with plain HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies. Just open `index.html` and it works.

The site serves as a central hub for Wazingwa's work as a Machine Learning Engineer based in Zambia, specializing in Computer Vision and deep learning.

## What's on the site

- **Intro** — who I am, what I do, and how to reach me
- **Tech Stack** — the tools and technologies I work with (Computer Vision, Deep Learning, React, Node.js, etc.)
- **Projects** — personal and commercial projects including Kapita, GrindCastZM, Aspira, and Go Ye Therefore Zambia
- **Social links** — X/Twitter, Threads, Bluesky, LinkedIn, and Substack
- **Contact** — email and Cal.com booking link

## Tech

- HTML5
- CSS3 (custom properties, dark mode, responsive grid)
- Vanilla JavaScript (theme toggle, clipboard copy, dynamic year)
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) — font via Google Fonts

## Features

- Light / dark mode with system preference detection and `localStorage` persistence
- One-click email copy to clipboard
- Fully responsive — works on mobile, tablet, and desktop
- No build step required — open the HTML file directly or serve with any static host

## Running locally

No install needed. Just clone the repo and open the file:

```bash
git clone https://github.com/WazDevZm/WazDevZm.github.io.git
cd WazDevZm.github.io
open index.html
```

Or use any local server:

```bash
npx serve .
```

## Deployment

Deployed via **GitHub Pages** directly from the `master` branch. Every push to `master` automatically updates the live site.
